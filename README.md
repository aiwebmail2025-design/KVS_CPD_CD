# 🎓 CPD Certificate Download Portal

A modern, secure and user-friendly web application designed to simplify the search, verification and distribution of CPD (Continuous Professional Development) certificates.

Participants can search for their certificates using their names, verify their email addresses through OTP authentication, preview matching certificates, select the required PDFs and receive them directly through email.

## ✨ Key Features

### 🔍 Smart Certificate Search
- Search certificates using participant names.
- Automatically searches PDF files stored in Google Drive.
- Case-insensitive name matching.
- Treats underscores (`_`), spaces and hyphens as equivalent.
- Automatically identifies programme names from PDF filenames.
- Displays all matching certificates.

### 🖼️ Certificate Preview & Selection
- Displays certificate thumbnails.
- Shows programme names and original PDF filenames.
- Individual certificate selection using checkboxes.
- Maximum 3 certificates per email.
- Users can select only the certificates they need.

### 🔐 OTP-Based Email Verification
- Six-digit OTP authentication.
- OTP delivered to the participant's email address.
- OTP expiration after 10 minutes.
- Limited verification attempts.
- Resend protection and request rate limiting.
- Supports Gmail, Outlook, Yahoo and iCloud email addresses.

### 📧 Automated Certificate Email Delivery
- Automatically emails selected certificates as PDF attachments.
- Multiple certificates delivered in a single email.
- Professional HTML email templates.
- Attractive OTP emails with large, clearly visible verification codes.
- Certificate delivery confirmation.
- Responsive email design.


## 🎯 Project Objective

To digitize and simplify certificate distribution by providing participants with a self-service portal where they can securely find, verify, select and receive their certificates without manual administrative intervention.

## 🚀 Benefits

- Saves administrative time.
- Reduces manual certificate distribution.
- Provides secure email verification.
- Makes certificate searching easier.
- Supports multiple certificate requests.
- Maintains automated activity records.
- Can be configured for different schools, institutions and organizations.
